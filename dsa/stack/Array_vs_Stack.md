| Feature              | Array                          | Stack                             |
| -------------------- | ------------------------------ | --------------------------------- |
| Purpose              | Store elements                 | Store elements with LIFO behavior |
| Rule                 | No specific ordering rule      | LIFO                              |
| Access               | Any index                      | Usually only top                  |
| Insert               | Can insert anywhere            | Usually at top                    |
| Delete               | Can delete from anywhere       | Usually from top                  |
| Main operations      | Access, insert, delete, search | Push, Pop, Peek                   |
| Indexing             | Yes                            | Usually no direct indexing        |
| Example              | List of students               | Stack of plates                   |
| Access first element | Possible                       | Not normal stack behavior         |
| Access last element  | Possible                       | Peek gives top element            |
