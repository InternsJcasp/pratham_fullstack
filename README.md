# What is a Data Structure?

## Definition

A Data Structure is a **way of organizing data so that it can be used efficiently**.

Don't memorize this.

Understand it.

Think of a cupboard.

A cupboard stores clothes.

A shelf stores books.

A drawer stores documents.

Different storage for different needs.

Similarly,

Different Data Structures store data in different ways.

---

Example

Instead of

```
Ram
Shyam
Mohan
Rita
```

scattered everywhere,

we store them in an organized way.

```
[
Ram
Shyam
Mohan
Rita
]
```

Now searching becomes easier.

---

# What is an Algorithm?

Now suppose someone asks

> Find Mohan.

There are many ways.

Method 1

Read every name one by one.

Ram ❌

Shyam ❌

Mohan ✅

Found.

Method 2

If names are sorted

```
A
B
C
D
E
```

Use a smarter method that jumps to the middle first instead of checking every name.

That smarter process is an algorithm.

---

## Definition

An **Algorithm** is a step-by-step process to solve a problem.

Think of it like a recipe.

Example:

Making tea.

Step 1

Boil water.

Step 2

Add tea leaves.

Step 3

Add sugar.

Step 4

Add milk.

Step 5

Serve.

These steps are an algorithm.

---

# Data Structure + Algorithm Together

Imagine

You have a library.

Data Structure = How books are arranged.

Algorithm = How you find a book.

Both are needed.

If books are arranged well but your searching method is poor,

finding books is still slow.

If your searching method is excellent but books are scattered,

again it's slow.

Both must work together.

# Why is DSA Important?

Imagine two students.

## Student A

Writes code that works.

Searching takes

```
10 seconds
```

---

## Student B

Searching takes

```
0.01 seconds
```

But one solved it much faster.

> Solve problems **correctly** and **efficiently**.
