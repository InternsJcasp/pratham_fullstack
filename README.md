## ⚡ Code Optimization

For every problem, I will try to follow:

```text
Understand
    ↓
Plan
    ↓
Write Code
    ↓
Test
    ↓
Analyze Complexity
    ↓
Optimize
```

### Example

Instead of only asking:

> "Does my code work?"

I will also ask:

> "Can this code be faster, use less memory, or be written more cleanly?"
